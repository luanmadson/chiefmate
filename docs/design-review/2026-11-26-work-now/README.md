# Design review: Work now

A project's page with made-up data: a project with local delivery, a summary kept from an earlier "Work now" session and, in the second set, a "Work now" session open with a short conversation. Captured in headless Edge at 1440×900 (computer) and 390×844 (phone), interface in Brazilian Portuguese. The app has one theme, dark: there is no light theme to capture. The folder paths are shown as `C:\Projetos\…`.
