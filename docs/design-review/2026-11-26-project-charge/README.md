# Design review: the conversation with the agent in charge

A project's page, with made-up data: 19 notices for the project (17 not seen yet) and a conversation with the agent in charge while it answers. Captured in headless Edge at 1440×900 (computer) and 390×844 (phone), interface in Brazilian Portuguese. The app has one theme, dark.
