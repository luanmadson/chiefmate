# Design review: the call bar

Made-up data: three projects and four calls from the crew. Loja virtual: the designer waits for the owner to create a test key on Stripe (a request to act, with an address). Blog de receitas: the generalist asks "Resend or SES?" (a question, Resend recommended); the writer's call about a cover photo was left for later with **Agora não**. Manual do cliente: the curator left a request and went on without waiting. Captured in headless Edge at 1440×1000 (computer) and 390×844 with touch (phone, through a stand-in for the remote access, so the phone sees itself as another device), interface in Brazilian Portuguese. The app has one theme, dark: there is no light theme to capture.
