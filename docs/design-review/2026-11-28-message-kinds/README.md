# Design review: the kinds of message in the conversation

Made-up data: the owner Ana and three projects (Loja virtual, Blog de receitas, Manual do cliente). The same conversation in both captures: a question of the owner's and the manager's plain answer, then six notices (a run merged, two proposals triaged, a pull request waiting for approval, a run that failed, the emergency lockdown engaged and the summary of the time away), a line of Chiefmate's own (the conversation compacted) and news still waiting in the queue under it (a step that needs the owner and a run finished). "After" has the marks the manager now writes, except on the pull request's notice, which shows the kind taken from its events. Captured in headless Edge at 1440×1200 (computer) and 390×844 with touch (phone), interface in Brazilian Portuguese; the environment is made up too, so the title bar says Claude Code was not found. The app has one theme, dark: there is no light theme to capture.

| Screen | Before | After | What to check |
|---|---|---|---|
| Conversation, computer | [before](before-conversation-desktop.png) | [after](after-conversation-desktop.png) | Before, every notice had the same brass rule and the same brass **AVISO** tag: a merge, a failure and the lockdown looked alike. After, each one has a rule on the left and a badge in its kind's color, with an icon and a word: **✓ Concluído** (green), **i Informação** (blue), **! Precisa de você** (orange), **✕ Falha** and **⚠ Alarme** (red), **≡ Resumo** (purple). **AVISO** is now a plain gray tag beside it. The line of the system has **>_ Sistema** (gray) and reads more easily than before (its gray rose from 3.2:1 to 6:1 on the panel). The manager's plain answer and the owner's message are as before. In the queue, the news has an orange rule (its strongest event needs the owner) and each event its icon: **!** "requer sua atuação", **✓** "execução terminou". |
| Conversation, phone: top | [before](before-conversation-top-phone.png) | [after](after-conversation-top-phone.png) | The owner's message, the plain answer, then **✓ Concluído** and **i Informação** beside the author and the time; the events on the line below. On the phone the **AVISO** tag gives way to the badge, so the head keeps to two lines. |
| Conversation, phone: middle | [before](before-conversation-middle-phone.png) | [after](after-conversation-middle-phone.png) | **! Precisa de você** (the longest badge goes to its own line), **✕ Falha**, **⚠ Alarme**: three kinds of red and orange, each with its own icon. |
| Conversation, phone: end | [before](before-conversation-end-phone.png) | [after](after-conversation-end-phone.png) | **⚠ Alarme**, **>_ Sistema**, **≡ Resumo**, and the queue with its icons. |

Contrast, measured on the conversation's panel (#101318): green 7.3:1, blue 7.4:1, orange 7.4:1, red 6.1:1, purple 7.3:1, gray 6.0:1; inside the badge's own wash, 5.0:1 at the least; the message's text on its faint wash, 12.5:1. The colors come from the app's own state colors (`--ok`, `--info`, `--urgent`, `--muted`); orange and purple are new (`--needs`, `--report`), with an orange far from the brass of the buttons.

Not captured: an answer the manager couldn't finish (red, **✕ Falha**, as before in red text), and the manager's text while it writes, whose mark is hidden as it comes.
